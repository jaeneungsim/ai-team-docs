Architecture decision records (ADRs) for the item API, the web pages and pr-triage. Each record has a status:

- {status:Proposed|Blue} still open. Do not build on it yet.
- {status:Accepted|Green} in force.
- {status:Superseded|Grey} replaced by a newer record, which the old record names.

Write a record when a decision is hard to reverse or keeps coming up in reviews. Never edit an accepted record to mean something else: write a new record and mark the old one superseded.
